# RemNote Card API

A small RemNote plugin for creating and verifying structured cards from explicitly supplied local payloads.

## Safety

- The repository contains generic plugin code only. It contains no study-guide content, credentials, or personal data.
- The included commands operate only on a top-level document named `Instinct API Disposable Test`.
- Production card generation is intentionally absent until disposable validation passes.

## Disposable test commands

1. `API Test: Create Disposable Fixture`
2. `API Test: Verify Disposable Fixture`
3. `API Test: Delete Disposable Fixture`

The fixture covers exact Unicode and punctuation, hierarchy, headings, color, forward and bidirectional cards, concept/descriptor, multiline list cards, cloze formatting, image rich text, structural readback, deletion, and idempotent recreation.
